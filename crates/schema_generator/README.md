# Zed Schema Generator

Generates JSON schemas for various Zed configuration files.

## Usage

```sh
cargo run -p schema_generator -- --help

# Static schemas (no runtime dependencies)
cargo run -p schema_generator -- theme
cargo run -p schema_generator -- icon_theme
cargo run -p schema_generator -- tasks

# Runtime-aware schemas
cargo run -p schema_generator -- keymap     # Initializes GPUI to get registered actions
cargo run -p schema_generator -- debug      # Generates with default adapters (base schema)
cargo run -p schema_generator -- settings   # Generates base schema (incomplete)
```

## Schema Types

### Fully Static Schemas
- **theme**: Complete static schema for theme JSON files
- **icon_theme**: Complete static schema for icon theme JSON files
- **tasks**: Complete schema with custom transforms (no runtime needed)

### Runtime-Aware Schemas
- **keymap**: Initializes Zed to register all actions and generate a complete schema with action autocomplete
- **debug**: Generates base schema without adapter-specific validation (adapters are added dynamically at runtime)
- **settings**: Generates base schema without runtime fonts/themes/languages (these are added dynamically at runtime)

## Notes

For the most complete schemas during editing, Zed's `json_schema_store` dynamically generates schemas with:
- Debug: Adapter-specific schemas from DapRegistry
- Keymap: All registered actions
- Settings: Available fonts, themes, and languages

The static schemas generated by this tool are suitable for documentation and basic validation, but may lack some autocomplete features that are only available at runtime.
